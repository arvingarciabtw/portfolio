## usage

the portfolio is intended to be navigated via keyboard, it's more fun that way!. here are the key bindings and the respective actions they do:

| key           | action                    |
| ------------- | ------------------------- |
| `h/←`         | move left                 |
| `j/↓`         | move down                 |
| `k/↑`         | move up                   |
| `l/→`         | move right                |
| `w/a/s/d`     | scroll up/left/down/right |
| `1/2/3/...`   | page sections             |
| `enter/space` | execute                   |
| `-/+`         | zoom                      |
| `[/]`         | font weight               |
| `p`           | reset position            |
| `r`           | reset all settings        |
| `t`           | switch theme              |
| `c`           | switch theme contrast     |
| `x`           | hide footer               |
